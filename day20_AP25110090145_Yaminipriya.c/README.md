1. The program takes details of multiple products such as ID, name, quantity, and price using 1D arrays and stores them for billing.


2. It uses a 2D array to create a bill table that arranges each product’s ID, quantity, and price in rows and columns.


3. Functions are used to separate tasks like taking input, preparing the bill table, calculating totals, and displaying the final bill.


4. Loops help repeat the input process for each product and also calculate totals for all items.


5. The program finally displays a formatted bill showing each product’s details, individual totals, and a grand Total amount
